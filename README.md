# 📱 Запуск Sirus WoW (.EXE) в Google Colab и Стриминг на Телефон (Бесплатно)

Этот репозиторий содержит готовые Jupyter Блокноты и скрипты для запуска **Sirus Launcher (World of Warcraft)** и любых других Windows-приложений (`.exe`) в среде Google Colab с возможностью интерактивной трансляции экрана прямо на экран вашего мобильного телефона через веб-браузер.

Все решения полностью бесплатны, безопасны и работают без сложной ручной настройки!

---

## 🎮 Решение для Sirus WoW: Идеальный обход блокировок через прямое скачивание клиента по HTTP

После детального изучения исходного кода лаунчера Sirus (`TorrentClient.ts`) мы обнаружили важнейшую деталь:
* Лаунчер Сируса использует встроенную бинарную C++ библиотеку торрент-загрузчика (`td-linux-x64`).
* Если папка игры пустая, лаунчер запускает эту C++ библиотеку для загрузки оригинальных 16 ГБ клиента. Сеть Google Colab блокирует торрент-порты, и лаунчер падает с бесконечными ошибками.
* **НО!** Если папка игры **не пустая и уже содержит чистый клиент WoW 3.3.5a**, лаунчер Сируса **вообще не запускает торрент-клиент!** Он переключается в режим **HTTP-скачивания**, проверяет файлы и быстро докачивает патчи Сируса по стандартному HTTP-протоколу. Это работает безупречно и со скоростью более 100 МБ/с!

## 🚀 Пошаговая инструкция по запуску Sirus WoW:

1. Откройте [Google Colab](https://colab.research.google.com/).
2. Перейдите во вкладку **Загрузить (Upload)** и выберите ранее скачанный файл блокнота **`sirus_colab_launcher.ipynb`**.
3. Запустите по очереди ячейки:
   * **Шаг 1: Установка системных библиотек** — установит графические утилиты, библиотеки рабочего стола и noVNC.
   * **Шаг 2: Запуск виртуального экрана и VNC** — поднимет невидимый экран высокого разрешения и стример.
   * **Шаг 3: Оригинальный запуск туннеля** — выдаст зеленую карточку с **QR-кодом** для твоего телефона. Отсканируй его телефоном, чтобы открыть стрим.
   * **Шаг 4: Прямое скачивание готовой WoW 3.3.5a по HTTP** — **САМЫЙ ВАЖНЫЙ ШАГ!** На терабитной скорости Google Colab скачает и распакует чистый клиент WoW 3.3.5a напрямую с серверов Internet Archive за 2 минуты.
   * **Шаг 5: Подключение папки скачивания и запуск лаунчера** — автоматически пропишет путь `/content/sirus-wow` в лаунчер и запустит его. Лаунчер сразу увидит файлы и без ошибок обновит клиент по HTTP!
   * **Шаг 6: Бесшумное удержание** — бесшумно удержит сессию активной в течение 6 часов.
