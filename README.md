# 📱 Запуск Sirus WoW (.EXE) в Google Colab и Стриминг на Телефон (Бесплатно)

Этот репозиторий содержит готовые Jupyter Блокноты и скрипты для запуска **Sirus Launcher (World of Warcraft)** и любых других Windows-приложений (`.exe`) в среде Google Colab с возможностью интерактивной трансляции экрана прямо на экран вашего мобильного телефона через веб-браузер.

Все решения полностью бесплатны, безопасны и работают без сложной ручной настройки!

---

## 🎮 Решение для Sirus WoW: Обход блокировок с прокси на Replit

По умолчанию Google Colab **намертво блокирует торрент-запросы**, которые делает Sirus Launcher для скачивания модифицированных файлов игры. Это приводило к ошибке *"Возникла проблема при попытке загрузки"* и сбросу папки игры.

Чтобы обойти это, мы разработали **сетевой прокси-мост через Replit (Transparent SOCKS5 Bridge)**. Он принимает трафик лаунчера в Colab, безопасно пересылает его через Replit и возвращает файлы. Для Google Colab это выглядит как обычное разрешенное веб-подключение!

## 🚀 Пошаговая инструкция по запуску Sirus WoW:

### Этап 1. Запуск Прокси-Моста на Replit
1. Перейдите на [Replit](https://replit.com/) и создайте новый проект (**Repl**), выбрав язык **Python**.
2. Перейдите во вкладку **Shell (Bash)** в правой панели Replit.
3. Вставьте туда следующую команду (одним кликом) и нажмите **Enter**:
   ```bash
   wget -O main.py https://github.com/wasiatop130/123-321/raw/arena/019f7597-123-321/replit_proxy_bridge.py && python3 main.py
   ```
4. В консоли появится надпись: `✅ SOCKS5 Proxy-Bridge is running on port 1080!`.
5. Скопируй адрес своего Replit (например, `socks5://project-name.username.replit.app:1080` — замени протокол `https://` на `socks5://` и в конце укажи порт `:1080`).

---

### Этап 2. Настройка и запуск в Google Colab
1. Откройте [Google Colab](https://colab.research.google.com/).
2. Перейдите во вкладку **Загрузить (Upload)** и выберите ранее скачанный файл блокнота **`sirus_colab_launcher.ipynb`**.
3. Нажмите Play по очереди на ячейках:
   * **Шаг 1: Установка системных библиотек** — установит графические утилиты, библиотеки рабочего стола и noVNC.
   * **Шаг 2: Запуск виртуального экрана и VNC** — поднимет невидимый экран высокого разрешения и стример.
   * **Шаг 3: Оригинальный запуск туннеля** — выдаст зеленую карточку с **QR-кодом** для твоего телефона.
4. Отсканируй QR-код телефоном, чтобы открыть трансляцию.
5. На **Шаге 4** (Подключение папки скачивания) в поле **`replit_socks5_proxy`** вставь скопированный адрес твоего прокси-моста из Replit.
6. Нажми **Play** на Шаге 4. Скрипт закроет лаунчер, пропишет папку игры `/content/sirus-wow`, завернет его трафик в Replit-мост и запустит лаунчер заново!
7. Нажмите Play на **Шаге 5 (Бесшумное удержание)**. Блокнот уйдет в фоновый режим и будет бесшумно держать сессию активной в течение 6 часов.

---

### 📱 Секреты удобного управления на телефоне:
* **Поверните телефон горизонтально (боком):** Экран трансляции развернется во весь дисплей, и все элементы лаунчера и игры станут крупными и удобными для тапов!
* **Как двигать окна:** Откройте боковое меню noVNC (свайп слева направо), нажмите на кнопку **`Alt`** (она зафиксируется) и тащите окно пальцем за любую его часть.
* **Как вызывать клавиатуру:** В боковом меню noVNC нажмите на иконку клавиатуры для ввода логина, пароля или путей.
